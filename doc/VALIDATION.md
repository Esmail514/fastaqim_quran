## تحقق تغيير الاسم التقني — 2026-10-07

أصبح الاسم `mushaf_riwayat` في المجلد و`pubspec.yaml` والاستيرادات ومسارات
الخطوط والأصول، ونُقل المثال وتطبيق فاستقم إلى نقطة الاستيراد الجديدة.
بقيت أسماء الواجهات وعائلات QCF وبيانات حفص وورش وسجل Git المحلي محفوظة.

- `flutter pub get --offline`: نجح في الباكج والمثال والتطبيق؛ فُحصت ملفات
  `package_config.json` الثلاثة للتأكد من اعتماد الاسم الجديد وحده.
- `flutter test --no-pub --reporter expanded`: نجحت اختبارات الباكج الـ62،
  واختبار المثال، واختبارات تطبيق فاستقم الـ505.
- التحليل بعد التنسيق: التطبيق دون ملاحظات؛ الباكج دون أخطاء أو تحذيرات
  ومع الملاحظات المعلوماتية التسع السابقة فقط.
- قورنت بصمات SHA-256 لجميع ملفات الأصول والترخيص الـ1234 قبل النقل وبعده؛
  تطابقت بالكامل. بقيت جميع ملفات الباكج الـ1428 التي يتتبعها مستودع التطبيق
  موجودة تحت المسار الجديد، بما فيها الملفات المولدة المتتبعة سابقًا.
- `python tool/build_docs.py`: نجح توليد مكتبة API الجديدة دون أخطاء أو
  تحذيرات؛ فُحصت مسارات 3924 رابطًا محليًا و59 رابطًا في أدلة Markdown.
- `flutter build apk --debug --no-pub`: نجح بناء Android. فُحص الأرشيف فعليًا:
  609 عائلات خطوط تحت الاسم الجديد، و1227 أصلًا مضمنًا ببصماته الأصلية،
  دون مفاتيح أصول أو عائلات خطوط تحت اسم الباكج القديم.
- يقتصر التنسيق على الأسطر المرتبطة بالنقل؛ حُفظ التنسيق السابق خارجها.

## تحقق التوثيق — 2026-10-07

هذه نتائج مرحلة التوثيق السابقة التي سبقت تغيير الاسم التقني. اقتصرت
تغييرات المصدر فيها على تصحيح ثلاثة مراجع في تعليقات التوثيق، دون تغيير
النص القرآني أو الخطوط أو السلوك أو دعم الروايات التنفيذي.

- `flutter pub get --offline`: نجح في الباكج والمثال.
- `flutter test --no-pub`: نجحت حالات الباكج الـ62.
- `flutter test --no-pub` داخل `example/`: نجحت حالة فتح المثال.
- `dart analyze lib` من جذر الباكج: دون ملاحظات.
- `flutter analyze --no-preamble --no-fatal-infos`: لا أخطاء أو تحذيرات؛ تسع
  ملاحظات معلوماتية سابقة في المثال واختبار قديم.
- فحص روابط Markdown المحلية: جميع مسارات الملفات المشار إليها موجودة.
- تحقق SHA-256 للأصول المشار إليها في manifests: نجح لـ612 ملفًا، منها
  النصوص والخطوط وهندسة الصفحات ورسوم ورش الثلاثة المضمنة وread-me حفص.
- `python tool/build_docs.py`: نجح توليد API دون أخطاء أو تحذيرات. صححت
  الأداة 14 رابطًا من الصفحة الرئيسية إلى الأدلة المحلية؛ نجح فحص مسارات
  3923 رابطًا محليًا في HTML المولّد، مع مراعاة ملفات الشريط الجانبي المضمنة.

النتائج التالية تصف التحقق السابق من تكامل الروايات؛ بناء web وتجربة فهارس
الصوت المباشرة لم يُعادا ضمن مهمة التوثيق.

التعديلات داخل `mushaf_riwayat` نفسه، دون إنشاء باكج جديد. حفص هي القيمة الافتراضية.

## تحقق البيانات والعرض

قورنت النصوص المقروءة ونصوص البحث لجميع آيات حفص الـ6236 بمصدر المجمع
الأصلي، وكذلك أرقام صفحاتها. بقيت رموز QCF الخاصة بعرض الآيات كما هي.
حُفظ ملف النص القديم دون تعديل للأرشفة؛ تستخدم الواجهات العامة المصدر
المصحح، وتعالج خلط نصوص ورش السابق مع أرقام حفص ووجود 22 قيمة نصية فارغة.

تغطي هندسة ورش الصفحات الـ604 والآيات الـ6214، في 6218 منطقة تتضمن أجزاء
أربع آيات تمتد بين صفحتين. تطابقت بصمات الملفات المستوردة مع الإصدار المثبت،
وبقي النص والخط الأصليان دون تحرير. اختُبر التحجيم والإحداثيات السالبة
والنقر والضغط المطول وتبديل الرواية ومنع النقر قبل اكتمال الرسم أو عند فشله.

اختُبر الرسم الحقيقي للصفحات الثلاث الأولى في Flutter، وفُحصت المعاينات:
`build/warsh-page-1.png` و`build/warsh-page-2.png` و`build/warsh-page-3.png`.
هذا لا يمثل مراجعة بصرية مستقلة لكل الرسوم الـ604.

## تحقق التلاوات

جُرب مزود MP3Quran فعليًا على فهرس الخدمة: 20 رواية و114 سورة، مع وجود
مجموعات كاملة لحفص وورش وورش من طريق الأزرق. شملت التجربة بناء قوائم
روابط السور الـ114 للمجموعات الكاملة؛ لم تُجلب ملفات صوتية.

اختبارات EveryAyah تتحقق من بناء الروابط وهوية الرواية وحدود الأرقام
والتحويلات الموثقة والتوقيتات المقدمة من التطبيق. ترقيم عبد الباسط ورش
في الشعراء والملك يحتاج تحويلًا موثقًا؛ وكذلك مقاطع الدوسري وياسين ذات
العد الكوفي عند ربطها بالعد المدني الأخير. لا يختار الباكج مقطعًا بالتخمين.

## حدود العرض

الرسوم الثلاثة الأولى لورش مضمنة؛ الرسوم الأخرى تستخدم روابط مصدر مثبت
عبر الإنترنت، ويمكن للتطبيق توفير رسوم محلية متطابقة. مصدر SVG يحفظ رسم
الكلمات وتوزيع السطور، لكنه يحذف الإطار وبعض عناصر رأس الصفحة وأرقامها
ويعيد رسم زخرفة علامات الآيات. تفاصيل الاستخدام في
[دليل الدمج](WARSH_INTEGRATION.md)، وحقوق المصادر في
[إشعارات المصادر](../THIRD_PARTY_NOTICES.md).
